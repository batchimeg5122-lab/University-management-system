# Брэнд зургууд

Энэ хавтсанд дараах 2 файлыг хийнэ. Нэр яг ижил байх ёстой.

| Файл | Хаана | Зөвлөмж |
|---|---|---|
| `logo.png` | Нэвтрэх хуудасны лого | Дөрвөлжин, тунгалаг дэвсгэртэй PNG, 256×256 эсвэл түүнээс том |
| `login-bg.jpg` | Нэвтрэх хуудасны зүүн талын зураг | Хэвтээ зураг, 1600px+ өргөн, 500KB-аас бага (TinyPNG, Squoosh-оор шахаж болно) |

Файлын нэр, өргөтгөлийг өөрчлөх бол `src/lib/brand.ts`-ийг засна.

Файл байхгүй бол систем анхдагч SVG лого болон хөх өнгөн дэвсгэрээр ажиллана.
Зургийг ашиглах эрхтэй эсэхээ шалгаарай (сургуулийн албан ёсны зураг эсвэл өөрийн авсан зураг).
